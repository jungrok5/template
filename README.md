# 프로젝트 베이스 템플릿

> **시제: 지금.** 여기 적힌 것은 **지금 이 저장소에 들어 있다** ([`CLAUDE.md`](./CLAUDE.md) §2.8).

**AI 가 개발 공정의 상당 부분을 수행하는 것을 전제로 한 저장소 뼈대.**
새 프로젝트를 시작할 때 이 저장소를 복사해 시작한다.

핵심 아이디어 하나: **사람의 주의력에 의존하는 규칙은 지켜지지 않는다. 도구가 강제하는 것만 규칙이다.**

---

| 파일 | 역할 |
|---|---|
| [`CLAUDE.md`](./CLAUDE.md) | **공통 작업 규칙.** AI 가 매 세션 시작 시 읽는다 |
| [`GLOSSARY.md`](./GLOSSARY.md) | 용어집 — 같은 개념에 다른 이름이 붙는 것을 막는다 |

## 새 프로젝트에서 할 일

1. **`CLAUDE.md` 의 `<!-- PROJECT -->` 를 채운다.**
   테스트 · 린트 · 타입 검사 명령, 컴포넌트 폴더 구조, 프로젝트 고유 원칙(§7).
2. **`.github/workflows/gates.yml` 에 실제 빌드 · 테스트 단계를 넣는다.**
3. **안 쓸 규칙은 지운다.** 규칙마다 비용이 있다.
   프로젝트 규모에 안 맞으면 삭제하고 **왜 뺐는지 한 줄 남긴다.** 조용히 어기지 않는다.
4. **첫 명세 항목을 쓴다.** `docs/spec/<영역>.md` 에 `SPEC-<영역>-001` 부터.
5. **`docs/docs-vs-code.json` 의 예시 항목을 지우고, 문서마다 시제를 정한다.**
   `.md` 를 만들 때마다 관문이 물어본다 — 미루면 그때 운다.
6. 이 `README.md` 를 프로젝트 소개로 바꾼다.

### 규모별 권장

| 규모 | 켜는 것 |
|---|---|
| 프로토타입 · 1인 | §1 문서 우선 · §2.5~2.8 문서 ↔ 코드 · §3 계획 문서 · §4.1~4.3 테스트 · §5 코딩 원칙 |
| 팀 · 다중 컴포넌트 | 위 + §2.1 용어집 · §2.4 명세 링크 · §4.2 관문 |
| 장기 운영 | 전부. 특히 §4.4 증거 · §4.5 트리거 · §4.6 정적 검사 |

⚠️ **§2.5~2.8 은 1인 프로젝트에도 켠다.** 명세 링크(§2.4)는 규모가 있어야 값을 하지만,
문서와 코드가 갈라지는 것은 **혼자 할 때 더 심하다** — 잡아 줄 사람이 없다.

## 명세 ↔ 코드 링크가 하는 일

명세에 ID 를 쓰고, 코드가 그 ID 를 주석으로 되가리킨다. 한쪽만 바뀌면 CI 가 실패한다.

```markdown
### SPEC-AUTH-003 · 세션 만료
- **상태** — ✅
- **구현** — `src/auth/session.ts`
- **검증** — `expires_session_after_idle_timeout`
```

```ts
// 명세: [SPEC-AUTH-003] 세션 만료
```

```bash
python3 tools/spec/check_spec_links.py
```

잡는 것: 명세가 가리키는 파일이 없거나 태그가 빠진 경우, 코드에만 있는 유령 태그,
사라진 검증 테스트, **상태가 완료인데 검증이 없는 항목**, 폐기 ID 재사용, ID 중복.

검사기는 **주석 문법을 파싱하지 않고 `[SPEC-…]` 문자열을 찾는다** — 언어와 무관하게 동작한다.
Python 3.10+ · 표준 라이브러리만 쓴다.

## 문서 ↔ 코드 검사가 하는 일

명세 링크는 **명세에 쓴 것**만 지킨다. 정작 다음 세션을 속이는 것은 그 밖의 산문이다.

```bash
python3 tools/docs/check_docs_vs_code.py
```

| 잡는 것 | 왜 |
|---|---|
| **지운 이름이 코드에 다시 나타난 것** | 개념보다 어휘가 오래 산다 |
| **지운 말을 묘비 없이 쓴 글** | 남은 말을 읽고 **없는 개념을 다시 만든다** |
| **「지금」 인 문서가 가리키는 없는 이름** | 찾으러 갔다가 없으면 다시 만든다 |
| **시제 표시가 없거나 등록부와 다른 문서** | 앞으로 할 일이 지금 있는 것으로 읽힌다 |

등록부는 [`docs/docs-vs-code.json`](./docs/docs-vs-code.json) 하나뿐이다.
같은 규약을 따른다 — 언어 중립 · 표준 라이브러리만 · 실패하면 종료 코드 1.

⚠️ **묘비를 허용하는 것이 이 검사의 핵심이다.** 「한때 그것이 있었고 왜 지웠는가」는
가장 값진 문장이라 막으면 안 된다. **되살아나는 것만** 막는다 ([`CLAUDE.md`](./CLAUDE.md) §2.5).
